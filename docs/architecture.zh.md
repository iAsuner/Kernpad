# Kernpad 实现说明

[English](architecture.en.md)　[项目首页](../README.md)

## 原生宿主与共享界面

macOS 宿主由 Swift、AppKit、WKWebView 构成；Windows 由 C#、WPF、WebView2 构成。两端共用 `Source/Web` 中的编辑、模板、布局与语言实现。Web 层发送受限命令，由各自原生宿主负责文件、系统验证、剪贴板、媒体和 PDF。Windows 不模拟 macOS 认证。

Web 源文件通过 `Source/build-web.py` 合并为本地资源，构建时带入应用。运行不依赖远程脚本或云端服务。外部网页导航、导入 HTML 和媒体都需要经过原生与共享层的限制。

## 存储与密钥

当前外层格式为 `kernpad-vault` 或 `kernpad-backup`，版本 3；算法为 AES-256-GCM，恢复派生使用 HKDF-SHA256。旧版本和密码派生槽不被接受。每库独立根密钥用于派生记录密钥，记录身份与用途参与认证，写入使用新随机 nonce。

加密根索引保存记录摘要、密文正文与模板归档。进入列表读取索引，受限预览最多请求 40 个 ID；只有打开详情才解密所需正文。列表预览不返回密码、正文和 OTP 种子。备份与恢复逐条重新加密，不把整库明文送入 Web 界面。

macOS 的设备令牌包含硬件包裹的私钥表示及加密根密钥，私钥操作要求本人验证；设备材料不进入备份。锁定时使认证上下文、会话票据和详情缓存失效。恢复密钥只在本机恢复路径使用，不能作为示例或日志内容。

普通便签、公开模板结构与明确公开的 OTP 采用明文语义。密码库媒体随记录加密，普通便签媒体随便签存储。临时便签的到期清理与普通回收站规则不同，具体行为见使用手册。

## 编辑与保存

记录有稳定 ID，组件有内部 ID，字段以导入标识参与映射。模板保存保留普通内容并清除凭据，通过规则列表关联组件、快捷粘贴与密码库列表展示。

Web 保存发送会话票据、已打开详情的编辑许可和记录补丁。摘要不能替代未打开正文，永久删除必须显式给出 ID。原生校验后原子替换文件；成功确认后才释放详情，失败保留输入。

自动保存采用防抖与写入队列，短写入不闪现成功提示。手动模式跟踪与已保存内容的差异；切换时可保存、放弃或取消。安全锁定优先结束访问，未提交私密修改加密暂存为独立草稿，解锁后检查原记录是否变化再恢复。草稿不进入备份。

## 排版、媒体与 PDF

编辑器使用 12 格布局、起始列、跨行与背景高度设置描述排版。拖入媒体会经过类型、大小和解码检查，再加入目标组件或新组件。媒体 URL 按需创建并在释放详情时清理。

PDF 预览与导出共享内容快照、尺度换算与分页规则，视频变为封面，秘密字段遮挡。macOS 使用独立受限 WebKit 渲染与原生导出；Windows 使用 WebView2。PDF 查看缩放不修改实际输出尺寸，也不会把未保存修改自动提交。
