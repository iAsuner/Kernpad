# 本周，把阅读带回生活。

**项目工作台**

Quiet Reading 是一项正在进行的五天阅读计划。

把稍后再读的文章，整理成真正愿意打开的阅读清单。每晚留出二十分钟：读一篇、写三句、记下一个新的问题。

## 01 / 这周只做好一件事

> 少收集一点，多理解一点。让每次阅读，都留下自己的判断。

**完成标准**：十篇精选文章、三个主题、一页自己的总结。资料保存在本机，出门或断网时也能继续。

- 选材
  - 保留真正想读的内容，删去重复收藏
  - 用 **一句话** 写清每篇文章值得读的原因
- 阅读
  - 把认同的观点和仍然存疑的部分分开
  - 用 `reading.md` 记录自己的问题，不急着复制答案

## 02 / 从计划到交付

| 时间 | 重点 | 留下什么 |
| --- | --- | --- |
| 周一 | 整理与筛选 | 十篇文章，分成三个主题 |
| 周二、三 | 精读与旁注 | 每篇三句话：观点、证据、疑问 |
| 周四 | 把观点放在一起 | 一张比较表，一份新的理解 |
| 周五 | 回看与分享 | 一页总结，导出一份 PDF |

## 03 / 给习惯一点结构

```json
{
  "project": "Quiet Reading",
  "minutesPerDay": 20,
  "mode": "offline",
  "capture": ["idea", "evidence", "question"]
}
```

配置留在代码块里，缩进和符号保持完整。文章的观点放在正文，**自己的判断**用粗体标出；暂时没有答案的地方，用 *斜体* 留给下一次阅读。
